SentinelOps: Enterprise Infrastructure Simulation Platform

SentinelOps simulates real-world enterprise infrastructure across SRE, DevOps, and Cybersecurity domains.

It models how production systems behave under observability, automation, logging, and security enforcement.

1. Problem Statement

Enterprise infrastructure is fragmented across monitoring, logging, automation, and security tools. SentinelOps unifies these into a single operational simulation.

3. System Flow (Execution Path)

4. Observability Layer

Prometheus collects metrics via Node Exporter. Grafana visualizes system health in real-time.

5. Incident Replay Timeline

6. Logging & Visibility

Centralized rsyslog aggregation enables cross-node correlation and incident tracing.

7. Automation Layer

Ansible enforces configuration consistency, security baselines, and system provisioning.

8. Security Architecture

SSH hardening, firewall rules, and Fail2Ban enforce secure access control.

9. CMDB System

Lightweight inventory tracking system built with PHP + SQLite and 60s auto-refresh.

10. Engineering Outcomes

Distributed systems design, SRE observability, cybersecurity enforcement, and automation modeling.
