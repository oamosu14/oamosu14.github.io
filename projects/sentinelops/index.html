SentinelOps Platform Case Study

SentinelOps: Hybrid SRE + Cybersecurity Infrastructure Platform

SentinelOps is a simulated enterprise-grade infrastructure environment designed to replicate real-world platform engineering, SRE operations, and cybersecurity enforcement across multiple virtual data centers.

---

1. Problem Statement

Modern infrastructure systems require integration between:
  • Observability (metrics, logs, alerts)
  • Automation (configuration management)
  • Security (access control, hardening, monitoring)
Most learning environments isolate these domains. SentinelOps was built to unify them into a single operational model.
---

2. System Architecture

Multi-site virtual infrastructure built using VirtualBox:
  • IND-DC (Monitoring + API + Logging)
  • FSH-DC (CI/CD + Dev + Test + Prod)
  • MCV-DC (Web + Auth + Database)
Core layers:
  • Prometheus → Metrics collection
  • Grafana → Visualization
  • Alertmanager → Incident alerts
  • Rsyslog → Centralized logging
  • Ansible → Automation layer
  • Linux Security Hardening → SSH, firewall, Fail2Ban

4. Observability Stack

Prometheus collects system metrics from all nodes using Node Exporter. Grafana provides visualization dashboards for:
  • CPU utilization
  • Memory pressure
  • Disk usage
  • Service health
Alertmanager routes system anomalies for incident simulation.
---

5. Automation Layer

Ansible is used as the configuration management system. Capabilities:
  • Centralized host configuration
  • System package management
  • Security policy enforcement
---

6. Security Architecture

Security controls implemented:
  • SSH key-based authentication
  • Root login disabled
  • Firewall rules (UFW)
  • Fail2Ban brute-force protection
---

7. CMDB / Inventory System

Lightweight infrastructure dashboard using:
  • PHP backend
  • SQLite database
  • Auto-refresh (60s updates)
Provides real-time visibility into:
  • Node status
  • IP mapping
  • Service roles
---

8. Operational Simulation

Failure scenarios were simulated to validate:
  • Alert generation
  • Log tracing
  • System recovery workflows
This validates real-world SRE incident response behavior.
---

9. Key Engineering Outcomes

This project demonstrates:
  • Distributed infrastructure design thinking
  • SRE observability implementation
  • Security-first system architecture
  • Automation-driven operations model
