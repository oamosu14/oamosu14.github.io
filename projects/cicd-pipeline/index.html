📌 Extended Linux Operations Scope

System Administration Core Tasks

User Management

  • Create and manage users and groups (adduser, usermod, passwd)
  • Configure sudo access using visudo
  • Manage authentication via SSH key-based login

File System Management

  • File permissions (chmod, chown)
  • Directory structure enforcement
  • Log file inspection and protection

System Monitoring

  • CPU monitoring (top, htop)
  • Memory usage (free, vmstat)
  • Disk usage analysis (df, du)

Security Hardening

  • SSH hardening (disable root login, key-based auth)
  • Firewall configuration (ufw)
  • Intrusion prevention (fail2ban)

Automation

  • Cron job scheduling
  • System update automation
  • Backup scripting (rsync, tar)

Practice Lab

  • VM-based Linux environment setup
  • Security hardening simulation
  • Monitoring script development
