SOC Lab — Security Operations Center Environment

This project simulates a lightweight Security Operations Center (SOC) environment with SIEM-like behavior, focusing on real-time event monitoring, detection logic, and incident response workflows.

Unlike traditional static labs, this system includes a browser-based SIEM simulation engine that models how SOC analysts interact with security telemetry.

Objectives

  • Simulate real-time security event ingestion
  • Model SIEM-style log processing and alerting
  • Demonstrate detection engineering concepts
  • Implement correlation logic for threat detection
  • Replicate SOC analyst workflows in a controlled environment

Core Capabilities (SIMULATED SIEM)

Event Ingestion Engine

Continuous generation of system, authentication, and network events in real time.

Detection Rules Engine

Simulated detection of brute-force attempts, anomalies, and privilege escalation patterns.

Correlation Layer

Multi-event pattern detection using threshold-based escalation logic.

SOC Dashboard Simulation

Live event stream with severity classification and continuous monitoring.

Implementation Context

This lab runs as a lightweight virtual SOC node inside a VirtualBox environment using Linux. It is designed to simulate SIEM behavior without requiring external enterprise tools.

It mirrors foundational components found in platforms such as Splunk, ELK Stack, and Wazuh.
